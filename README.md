# 📞 Lista Telefônica

## 📌 Sobre o projeto
Sistema de lista telefônica desenvolvido em Java para gerenciamento de contatos, permitindo cadastrar, buscar, atualizar e remover informações.

O projeto foi criado com foco em praticar lógica de programação, Programação Orientada a Objetos (POO) e organização de código.

---

## 🚀 Tecnologias utilizadas
- Java
- Programação Orientada a Objetos (POO)
- Collections
- Estruturas de Dados
- Git e GitHub

---

## ⚙️ Funcionalidades
- ✅ Cadastro de contatos
- ✅ Busca de contatos
- ✅ Atualização de contatos
- ✅ Remoção de contatos
- ✅ Listagem de contatos

---

## 🧠 Conceitos aplicados
- Encapsulamento
- Classes e Objetos
- Métodos
- Collections

- Manipulação de dados
